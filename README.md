# DevTrack — Personal SDE Task & Application Tracker

Frontend-only React + Vite dashboard designed for GitHub Pages.

## Features
- Daily task tracker with status, priority, category and due date
- SDE application pipeline: Applied → OA → Interview → Offer / Rejected
- Dashboard statistics and analytics
- Responsive dark UI
- Browser localStorage persistence (no backend required)
- GitHub Pages compatible via relative Vite base path

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Deploy the generated `dist` folder to GitHub Pages, or use a GitHub Actions Pages workflow.
